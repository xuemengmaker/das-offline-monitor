# DAS 离线回放监测与自动背景分级预警系统 软件需求与验收标准

## 1. 项目定位

本系统是在 Ubuntu Linux 中运行的本地 DAS 离线回放监测软件。它仅读取配置目录下的 TDMS 历史数据，执行信号特征计算、自动背景学习、异常初筛和分级预警，并在本地网页中展示结果。

系统不接入真实仪器实时采集链路，不将异常初筛结果表述为真实泄漏的最终确认。

## 2. 用户使用流程

1. 操作人员在浏览器打开本地操作台。
2. 选择数据根目录下的 TDMS 相对路径，设置通道范围、时间窗和背景参数。
3. 创建分析任务，获得任务编号。
4. 系统读取指定数据窗口，完成特征、背景和预警计算。
5. 操作人员查看任务状态、图表、红橙黄结果表和日志摘要，并导出结果。

## 3. 第一版功能需求

### 3.1 数据与安全

- 数据根目录在 Linux 配置为 `/mnt/f/数据`，仅允许读取。
- API 和网页只接收相对路径，拒绝 `..` 和根目录外的路径。
- 读取前校验文件存在、扩展名为 `.tdms`、通道范围和时间窗合法。
- 限制单次分析的最大通道数和样点数，避免大文件导致内存耗尽。

### 3.2 分析任务

- 创建任务后立即返回 `job_id` 和 `queued` 状态。
- 任务状态为 `queued`、`running`、`completed` 或 `failed`。
- 保存任务参数、创建/开始/结束时间、耗时、错误摘要和结果位置。
- 任务完成后提供 JSON、CSV 结果和图表数据。

### 3.3 信号分析与预警

- 计算指定通道/窗口的均值、RMS、峰值和频谱特征。
- 从多数稳定通道建立自动背景池。
- 使用中位数、MAD 和鲁棒 Z 分数比较通道与背景差异。
- 结合 RMS 异常、本地 RMS 比、频谱偏离和连续通道条件进行初筛。
- 输出正常、黄色、橙色、红色四级结果；相邻红色通道合并为预警区间。
- 明确在结果中标记：预警仅为异常初筛，需结合现场复核。

### 3.4 网页操作台

- 提供文件选择、参数表单、开始分析、任务状态和结果导出操作。
- 展示通道 RMS、异常空间分布、预警统计与逐通道结果表。
- 展示任务日志摘要和失败原因。

### 3.5 日志与结果

- 日志包含时间、级别、`job_id`、文件相对路径、通道范围、耗时和异常堆栈。
- 结果以 SQLite 保存任务摘要，以 JSON/CSV 保存每次分析明细。
- 不复制、写入、移动或删除原始 TDMS 文件。

## 4. 非功能需求

- 第一版仅支持本机/局域网本地演示，不实现账号、权限或公网部署。
- 对有限通道和有限时间窗的分析应有可记录的耗时；性能结论只针对具体测试窗口。
- 代码模块可独立单元测试，接口可独立集成测试。
- 运行环境为 Ubuntu Linux；开发环境使用独立 Python 虚拟环境。

## 5. 验收标准

1. 能在 Ubuntu 启动服务，并通过浏览器访问本地操作台。
2. 能从 `/mnt/f/数据` 读取一个真实 TDMS 文件的指定窗口，且不修改原始文件。
3. 能创建任务、查询状态、获得结果和导出 JSON/CSV。
4. 能输出四级初筛结果、背景池信息与异常通道/区间。
5. 能在 Linux 日志中按 `job_id` 查询一次任务的完整过程。
6. pytest 覆盖核心计算、参数边界、异常任务和至少一个端到端分析链路。
7. Allure 报告显示测试执行结果；Git 中保存可复现的运行说明。
